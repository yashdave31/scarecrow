Three things happen.

Describe

Write a filter in plain words, or add a keyword list. Add as many as you like.

Scroll

Scarecrow checks each tweet before X shows it. Matches fold into a one-line note, so nothing flashes by.

Peek

Click a note to read the tweet anyway. A small counter shows how many Scarecrow kept out today.

What it actually does.

It looks at pictures and video.

A vision model describes each image and a few frames of each video. Your filters judge that description along with the tweet's text. Some protected videos can't be sampled, so those fall back to the thumbnail.

Install it

  • Clone the repo from GitHub
  • Open chrome://extensions and turn on Developer mode
  • Click Load unpacked and pick the folder
  • Add a filter, then refresh your X tabs

What it costs to run

Nothing for keyword filters. Described filters and image checks send requests to OpenRouter or NanoGPT, billed to your own account under your own key. You pay the provider directly, and only for what you use.

The fine print, up front.

Where your data goes

Your API key stays in your browser. Tweet text goes to the provider you pick (OpenRouter or NanoGPT) under your key. With image checks on, images and video frames go there too. Nowhere else.

The vision model is told not to recognize faces. A filter about a person matches an image only if their name is visible.

Where it falls short

The decisions come from Jev, a model still in beta, so it will sometimes be wrong. Every hidden tweet leaves a note you can open.

Videos are judged on a few frames, not the audio. When X changes its page markup, tweet detection can break until we patch it.

Questions.

Which browsers work?

Chrome. Other Chromium browsers should work too, but we haven't tested them.

Does it hide ads or promoted posts?

Only if your filter describes them. Scarecrow has no special ad rules.

What does it cost to run?

The extension is free. Described filters and image checks send requests to OpenRouter or NanoGPT, and your account there is billed. Keyword filters make no requests at all.

Can I get a tweet back once it's hidden?

Yes. Every hidden tweet leaves a one-line note, and one click shows it.

Is anything stored on a server?

Nothing. Your filters and key stay in your browser, and tweets go only to the provider you chose.
